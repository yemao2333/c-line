# 01 豆包通道说明：怎么把任务交给执行端

结论先说：**没有 HTTP API、没有 MCP 服务、没有 CLI**。本机跑的豆包是桌面客户端里的 agent，57587 / 49853 是客户端内部通道，对任意路径回 404、CDP 也探不到，属正常现象——那两个端口不是给外部调用的，别在它们身上继续花时间。

真正可用的只有三条，按稳定性排序。

---

## 通道 1 文件投递（推荐，可异步）

执行端每次被唤醒都会读一个固定目录。把任务写成文件丢进去即可：

```
<ROOT>\cool_fox-优化方案\20-共创-C线\inbox\task-YYYYMMDD-HHMM-<两位序号>.md
```

文件头必须带这五个字段，缺一项执行端会退回而不是猜：

```markdown
---
task_id: r01-a1                 # 轮次-字母-序号，回填时原样带回
kind: build | test | bench | probe | patch-apply
timeout_s: 900
artifact: <ROOT>\cool_fox\cool_fox-main   # 被作用的对象目录或产物
reply_to: outbox
---

## 目标
一句话说清这条命令要拿到哪个数字或哪个日志行。

## 命令
逐行给 PowerShell 原文，执行端原样跑，不解释、不改写。

## 验收
通过 / 不通过怎么判，给阈值或要抓的日志正则。

## 失败时回填什么
例如「build-final.log 第一个 error[ 起 40 行」。
```

执行端把结果写到 `outbox\<task_id>-result.md`，结构固定四段：

```markdown
## 状态
EXIT=…  elapsed=…s

## 数字
（脚本末行原样、bench.csv 追加行、目标日志正则命中行）

## 证据路径
<ROOT>\cool_fox-优化方案\data\<文件>

## 异常
崩溃 / 超时 / 无进程 / 空日志，附最后 20 行
```

投递后需要人在对话里说一句「inbox 有活」，执行端才会去读；或者让执行端挂一个定时任务每 15 分钟扫一次 inbox（要的话说一声，一条命令就能挂上）。

---

## 通道 2 对话转发（最省事）

把清单、命令块、报错直接贴进对话。执行端照跑，结果直接回在对话里，同时落 `data\`。适合一次性、短、需要人当场判断的任务。

---

## 通道 3 定时任务（真正的无人值守）

用本机定时任务让执行端按 cron 唤醒、扫 inbox、跑完写 outbox。适合「整晚跑 A/B 矩阵、每轮跑完自动回填」这类。需要事先约定：允许执行端在无人确认时启动游戏进程的最长时间、以及单轮失败是否自动重试。

---

## 执行端的硬边界（写给代码侧）

| 边界 | 说明 |
| --- | --- |
| 不改源码 | `15` 清单已写明「豆包不要改源码」，执行端照办；要改码请在 inbox 里给完整 diff 或给 `patch-apply` 任务 |
| 不碰 `rust-toolchain.toml`、`crates/victory-shader/**`、`policy.rs` | 与 `15` §5 一致 |
| 不自行决定重启机器 | 页面文件脚本 `12-页面文件.ps1` 只由人执行；执行端只做「改前快照 + 改后核对」 |
| 进程收尾 | 一律按映像名清理（`Get-Process -Name victory | Stop-Process -Force`），不用 pid |
| 跑分前先查额度 | `Commit Free` 低于 6 GB 不启动，先报数 |

---

## 环境坑（省得下一轮再踩）

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| `cargo` 不是命令 | 工具进程 PATH 不含 `<RUST>\cargo\bin` | 前置 `$env:PATH="<RUST>\cargo\bin;<TOOLCHAIN>\w64devkit\w64devkit\bin;C:\Windows\System32;"+$env:PATH`，并设 `CARGO_HOME=<RUST>\cargo`、`RUSTUP_HOME=<RUST>\rustup` |
| `dlltool.exe: program not found` | w64devkit bin 不在 PATH | 同上，必须带 `<TOOLCHAIN>\w64devkit\w64devkit\bin` |
| `cmd` / `taskkill` 找不到 | 工具进程 PATH 缺 `C:\Windows\System32` | 一律绝对路径调用 |
| 启动脚本退出码 9009 | `.cmd` 用了 LF 换行 | 存成 CRLF |
