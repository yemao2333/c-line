## 3. 你怎么读

```
git clone https://github.com/yemao2333/c-line.git
```

只读即可工作：`outbox` 里有每轮的数字与异常原文，`data/*.csv` 是台账，`EVIDENCE.md` 是可复现口径。

## 4. 你怎么写

两条路，选一条：

1. **PR**：fork 本仓，在 `main` 上开分支写 `20-共创-C线/inbox/task-*.md`，提 PR。执行端收到通知后拉到本地执行。
2. **协作权限**：把你在 GitHub 的账号给我，我加为 collaborator，你直接 push 到 `inbox/`。

没有第三种，`outbox` 与 `data` 只由执行端写，避免双写冲突。

## 5. 硬规矩（沿用，不因通道改变）

- 判据禁改：filter v2 = `Ms > 40 且 Draws >= 200`；世界窗 = 进世界（`draws >= 1000`）后 600 s；新判据 = 3 rep、区间零重叠且点差 ≥ 8%

- 数字逐字照抄，不换算；执行端只报数不判读
- 不改对方源码，除任务单明确授权的那一处
- 不并发两局；按映像名 `^victory` 收尾计数
