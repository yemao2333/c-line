## 目标

把 `r02-a10` 没拿到的那段补上：**世界内**的「卡上时间按 pipeline 归因」。

`r02-a10` 的结论（代码侧判读）：instrumentation **能用**（183 条 `the card's time by what ran` 都打出来了），但那次 150 s 只跑到负载 32 lists / 最高 **49.9 ms** a frame —— 世界内应当是 200 lists 量级、200 ms 量级。原因是 `VICTORY_GPU_TIMING` 会把 `late_stage()` 强制置 0（`host.rs:2381`：设了 `VICTORY_GPU_TIMING` 就 `return 0`），等于关掉了 late-wait 优化，diag 产物加载更慢，**150 s 没进世界**。

所以本任务：**同一份 diag 产物，跑 420 s**，并且每 10 秒记一次窗口标题（证明到底进没进世界、draws 到多少），结束时把世界内的 `by what ran` 行抓回来。

## 命令

```powershell
$diag = '<ROOT>\cool_fox\cool_fox-main\target\diag\victory.exe'
"SHA256_diag=" + (Get-FileHash $diag -Algorithm SHA256).Hash   # 期望 710857B5…15DA7C7D5

$env:VICTORY_AMBIENT_AIR='1.5'; $env:VICTORY_CACHE_DIR='<ROOT>\victory-data\coolfox-cache'; $env:VICTORY_DATA_DIR='<ROOT>\victory-data\coolfox-data'
$env:VICTORY_TEXTURE_NO_WAIT='1'; $env:VICTORY_RELAY='2'; $env:VICTORY_WIDE_BACK='1'; $env:VICTORY_CARD_REHASH_RUNS='1'
$env:VICTORY_JOIN_COPIES='1'; $env:VICTORY_INDIRECT_WINDOW='1'; $env:VICTORY_RELAY_COPY='1'; $env:VICTORY_CARD_STEPS='2'
$env:VICTORY_INDIRECT_BATCH='2'; $env:VICTORY_MAP_THREADS='1'; $env:VICTORY_CARD_AWAKE='1'; $env:VICTORY_SHOW_AFTER='1'
$env:VICTORY_AMBIENT='0.8'; $env:VICTORY_THIN='1'; $env:VICTORY_JOIN_PARTS='6'; $env:VICTORY_UPLOAD_AHEAD='1'
$env:VICTORY_LEVELS_ON_DEMAND='1'; $env:VICTORY_CARD_BUFFERS_MIN_KB='64'

$err = '<ROOT>\cool_fox-优化方案\data\r02-a11-gputiming-info.err.log'

  -ArgumentList @('run','<ROOT>\<DUMP>\game_scarlett_master.exe','--console','series-s','--execute') `
  -WorkingDirectory '<ROOT>\cool_fox\cool_fox-main' -RedirectStandardOutput $out -RedirectStandardError $err -PassThru -WindowStyle Normal

# 每 10 秒记一次窗口标题：证明进没进世界、draws 到多少
$titles = @()
for ($i = 1; $i -le 42; $i++) {
  Start-Sleep -Seconds 10
  $v = Get-Process -Id $p.Id -ErrorAction SilentlyContinue
  if (-not $v) { "process gone at $($i*10)s"; break }
  $t = $v.MainWindowTitle
  $titles += ("{0}s|{1}" -f ($i*10), $t)
  if ($i % 6 -eq 0) { "  t=$($i*10)s title=$t" }
}
$titles | Where-Object { $_ -match 'draws' } | Select-Object -Last 3

Get-Process | Where-Object { $_.ProcessName -match '^victory' } | Stop-Process -Force -ErrorAction SilentlyContinue

"err_bytes=" + (Get-Item $err).Length

Select-String -Path $err -Pattern "the card's time by what ran" -SimpleMatch | Select-Object -Last 5 | ForEach-Object { "L$($_.LineNumber): " + ($_.Line -replace '\x1b\[[0-9;]*m','') }

"=== 同段落的 waits 行末 3 条 ==="
Select-String -Path $err -Pattern 'waits for every earlier shader write' -SimpleMatch | Select-Object -Last 3 | ForEach-Object { "L$($_.LineNumber): " + ($_.Line -replace '\x1b\[[0-9;]*m','') }

"=== 是否出现「世界内标志行」==="
"settles_hits=" + @(Select-String -Path $err -Pattern 'of the waiting for the card in settles' -SimpleMatch).Count
"thin_hits="    + @(Select-String -Path $err -Pattern 'list calls translated by threads of ours per frame' -SimpleMatch).Count
```

## 失败时回填什么

- 420 s 内没出现 `draws > 1000` 的标题 → 回填所有 `titles` 记录（最多 42 条）+ `err_bytes`，代码侧据此决定是否再加时。
- 进程早退 → 第几秒 + `.err.log` 最后 40 行 + 是否出现 `device removed` / `out of memory` 字样。
- 无 `by what ran` 行 → 贴 `Select-String -Pattern 'copystat'` 命中的前 10 行。
