## 目标

拿到**「等卡 197 ms 到底是谁在跑」**的按管线归因。仓库自带这个能力，但只编在 `diagnostics` feature 里：

- `crates/victory-gpu/src/copystat.rs:210`：`WAITS_BY_WORK` ——「等卡的等待，**按跑的是什么（lists 与 pipelines）**分组：次数、微秒」；
- `copystat.rs:213`：`COMMANDS_BY_WORK` —— 开 `VICTORY_GPU_TIMING` 时，「这些命令在卡上的时间，**按它们跑的东西（pipeline 或命令种类）**分组：次数、微秒、最长的一条」；
- `crates/victory-gpu/src/timeline.rs`：`VICTORY_TIMELINE` 可写 Chrome trace + 文本摘要（含「卡：每次提交的开始与结束」）。

这些都在 `#[cfg(feature = "diagnostics")]` 后面，而 `target\release\victory.exe` 是**没有** diagnostics 的 release 产物 —— 所以至今没采到。

两步：**先编 diag 产物，再用它跑一局 info 级**。

## 命令

### S1：编 diag 产物（不覆盖 release 产物）

```powershell
$env:CARGO_HOME = "<RUST>\cargo"; $env:RUSTUP_HOME = "<RUST>\rustup"
$env:PATH = "<RUST>\cargo\bin;<TOOLCHAIN>\w64devkit\w64devkit\bin;C:\Windows\System32;" + $env:PATH
$env:RUSTFLAGS = "-C target-cpu=native"
cd <ROOT>\cool_fox\cool_fox-main
$log = "<ROOT>\cool_fox-优化方案\data\build-diag.log"
$t0 = Get-Date
cargo build --profile diag -p victory --features diagnostics --locked *> $log
"EXIT=$LASTEXITCODE elapsed=$([int]((Get-Date)-$t0).TotalSeconds)s"
"errors=" + @(Select-String -Path $log -Pattern '^error' | Select-Object -First 5).Count
$d = Get-Item target\diag\victory.exe -ErrorAction SilentlyContinue
if ($d) { "diag_bytes=$($d.Length) written=$($d.LastWriteTime.ToString('yyyy-MM-dd HH:mm:ss'))" ; "diag_sha256=" + (Get-FileHash $d.FullName -Algorithm SHA256).Hash } else { "diag_exe=NOT_FOUND" }
"release_sha256=" + (Get-FileHash target\release\victory.exe -Algorithm SHA256).Hash
```

**必须回填**：`datg`/`diag_bytes`、`diag_sha256`、`release_sha256`（后者必须仍是 `58E60D62…A4EFF45`，证明 release 产物没被覆盖）。

### S2：用 diag 产物跑一局 info 级 + GPU 计时（150 s）

```powershell
$env:VICTORY_AMBIENT_AIR='1.5'; $env:VICTORY_CACHE_DIR='<ROOT>\victory-data\coolfox-cache'; $env:VICTORY_DATA_DIR='<ROOT>\victory-data\coolfox-data'
$env:VICTORY_TEXTURE_NO_WAIT='1'; $env:VICTORY_RELAY='2'; $env:VICTORY_WIDE_BACK='1'; $env:VICTORY_CARD_REHASH_RUNS='1'
$env:VICTORY_JOIN_COPIES='1'; $env:VICTORY_INDIRECT_WINDOW='1'; $env:VICTORY_RELAY_COPY='1'; $env:VICTORY_CARD_STEPS='2'
$env:VICTORY_INDIRECT_BATCH='2'; $env:VICTORY_MAP_THREADS='1'; $env:VICTORY_CARD_AWAKE='1'; $env:VICTORY_SHOW_AFTER='1'
$env:VICTORY_AMBIENT='0.8'; $env:VICTORY_THIN='1'; $env:VICTORY_JOIN_PARTS='6'; $env:VICTORY_UPLOAD_AHEAD='1'
$env:VICTORY_LEVELS_ON_DEMAND='1'; $env:VICTORY_CARD_BUFFERS_MIN_KB='64'
$env:VICTORY_LOG = 'info'
$env:VICTORY_GPU_TIMING = '1'
Remove-Item Env:\VICTORY_TIMELINE -ErrorAction SilentlyContinue

Get-Process | Where-Object { $_.ProcessName -match '^victory' } | Stop-Process -Force -ErrorAction SilentlyContinue
Start-Sleep 3
$err = '<ROOT>\cool_fox-优化方案\data\r02-a10-gputiming.err.log'
$out = '<ROOT>\cool_fox-优化方案\data\r02-a10-gputiming.log'
$p = Start-Process -FilePath '<ROOT>\cool_fox-优化方案\..\cool_fox\cool_fox-main\target\diag\victory.exe' `
  -ArgumentList @('run','<ROOT>\<DUMP>\game_scarlett_master.exe','--console','series-s','--execute') `
  -WorkingDirectory '<ROOT>\cool_fox\cool_fox-main' -RedirectStandardOutput $out -RedirectStandardError $err -PassThru -WindowStyle Normal
"pid=$($p.Id)"
Start-Sleep -Seconds 150
Get-Process | Where-Object { $_.ProcessName -match '^victory' } | Stop-Process -Force -ErrorAction SilentlyContinue
Start-Sleep 2
"err_bytes=" + (Get-Item $err -ErrorAction SilentlyContinue).Length
"=== 关键行：按「跑的是什么」归因的等卡时间（取最后 3 条）==="
Select-String -Path $err -Pattern 'by what ran|commands|of the waiting for the card in settles' | Select-Object -Last 3 | ForEach-Object { ($_.Line -replace '\x1b\[[0-9;]*m','') }
```

**若 S2 在 30 秒内就死**（诊断开销大），重试一次，把 `VICTORY_GPU_TIMING` 保留、其它一切不动；仍死就照实回填并停。

## 禁止事项

1. **不得改写任何数字**：`EXIT`、`diag_bytes`、SHA256、整行日志原文都不许截断改写。
2. **不得改变论证方向**：只回填日志原文，不判断「哪个 pass 慢」——归因由代码侧做。
3. **不得自行补充未经核实的结论**：不解释 pipeline 名的含义。
4. **不得覆盖 `target\release\victory.exe`**；不得改 `Cargo.toml` / `.cargo\config.toml` / 源码。
5. 不得为了「跑得更久」延长 `Start-Sleep`；150 s 到点就收。
6. 不得在 S2 里开 `VICTORY_CAPTURE_FRAMES` / `VICTORY_RECORD_FRAMES`（会让标题自己的看门狗结束进程）。
7. 收尾一律 `^victory` 正则 + 计数。

## 失败时回填什么

- S1 失败：`data\build-diag.log` 里第一个 `error[` 起 40 行。
- S2 早退：`r02-a10-gputiming.err.log` 最后 40 行 + `Get-Process victory*` 计数 + 是否重试过。
- 找不到 `by what ran` 行：贴 `Select-String -Pattern 'timing|stamps|GPU'` 命中的前 20 行，便于代码侧判断开关是否生效。
