## 每个补丁的固定流程

```powershell
$repo='<ROOT>\cool_fox\cool_fox-main'; $pat='0032-contiguous-readback-copies.patch'
$tag = $pat -replace '\.patch$',''

# 1) 备份（每个补丁各一份，不许覆盖）
Copy-Item "$repo\target\release\victory.exe" "$repo\target\release\victory-pre-$tag.exe" -ErrorAction SilentlyContinue

# 2) 试打（只打在 host.rs 上；不许改其它文件）
Push-Location $repo
& git apply --check --verbose "<ROOT>\kelvaroq-main\native\patches\$pat" 2>&1 | Select-Object -First 20
"check_EXIT=$LASTEXITCODE"
Pop-Location
```

- `check_EXIT ≠ 0`（上下文对不上）→ **不要手改冲突**，直接跳到下一个补丁，回填写「apply 失败 + 前 20 行原文」。
- `check_EXIT = 0` → 真正打：
```powershell
Push-Location $repo
& patch -p1 -i "<ROOT>\kelvaroq-main\native\patches\$pat" 2>&1 | Select-Object -Last 10
"patch_EXIT=$LASTEXITCODE"
& git diff --stat 2>&1 | Select-Object -Last 5
Pop-Location
```
（`git apply` 可用就用 `git apply`；`patch` 不可用则用 `git apply -p1`。）

- 编译：
```powershell
$env:CARGO_HOME='<RUST>\cargo'; $env:RUSTUP_HOME='<RUST>\rustup'
$env:PATH='<RUST>\cargo\bin;<TOOLCHAIN>\w64devkit\w64devkit\bin;C:\Windows\System32;'+$env:PATH
$env:RUSTFLAGS='-C target-cpu=native'
Push-Location $repo; cargo build --release --locked -p victory *> "<ROOT>\kelvaroq-eval\build-$tag.log"; "build_EXIT=$LASTEXITCODE"; Pop-Location
"errors=" + @(Select-String -Path "<ROOT>\kelvaroq-eval\build-$tag.log" -Pattern '^error' | Select-Object -First 3).Count
```
- 跑冒烟：
```powershell
cd <ROOT>\cool_fox-优化方案\10-实验脚本
.\smoke.ps1 -Label "port-$tag"
"smoke_EXIT=$LASTEXITCODE"
```
- **失败即回滚**该补丁（`git apply -R` 或用备份还原 host.rs），再进下一个。
