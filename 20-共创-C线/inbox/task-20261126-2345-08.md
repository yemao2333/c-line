## 目标

收尾核对：用户重启一次之后，确认页面文件设置**持久化**、`Commit Limit` 仍在 48 GB 以上，并把三行读数回填。本批次不再跑分。

> 前置：`r02-a7` 已验收通过（`round-02\F-核对结论.md` §10），决定已落 `11-实施记录.md` §9 与 `30-结项报告.md`。

## 命令

```powershell
$t = Get-Date -Format 'yyyy-MM-dd HH:mm:ss'
"post_reboot_at=$t"
Get-CimInstance Win32_PageFileUsage | Select-Object Name, AllocatedBaseSize, PeakUsage | Format-Table -AutoSize
Get-CimInstance Win32_PageFileSetting | Select-Object Name, InitialSize, MaximumSize | Format-Table -AutoSize
$c = (Get-Counter '\Memory\Commit Limit','\Memory\Committed Bytes' -SampleInterval 1 -MaxSamples 1).CounterSamples
"commit_limit_gb=" + [math]::Round((($c | Where-Object Path -match 'commit limit').CookedValue) / 1GB, 2)
"commit_used_gb="  + [math]::Round((($c | Where-Object Path -match 'committed bytes').CookedValue) / 1GB, 2)
"automatic_managed=" + (Get-CimInstance Win32_ComputerSystem).AutomaticManagedPagefile
```

## 验收标准

| 项 | 通过线 |
| --- | --- |
| `G:\pagefile.sys` 设置 | 仍在（InitialSize 16384 / MaximumSize 32768） |
| `commit_limit_gb` | **≥ 48** |
| `automatic_managed` | `False` |
| 时间戳 | 回填 `post_reboot_at` 原值 |

## 禁止事项

1. **不得改写任何数字**：`commit_limit_gb` / `AllocatedBaseSize` / 时间戳原样搬。
2. **不得改变论证方向**：`commit_limit_gb < 48` 就照实写并标「设置未持久化」，不得写「基本正常」。
3. **不得自行补充未经核实的结论**：不解释为何变化。
4. 不得改任何页面文件设置、不得卸载/删除 `G:\pagefile.sys`。
5. 不得在本任务里跑游戏或跑分。

## 失败时回填什么

- 设置表里没有 `G:` → 贴 `Get-CimInstance Win32_PageFileSetting` 全文 + `Win32_PageFileUsage` 全文。
- `Get-Counter` 报错 → 贴错误原文 + `(Get-CimInstance Win32_OperatingSystem).TotalVirtualMemory`。
