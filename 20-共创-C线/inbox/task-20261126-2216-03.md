## 验收标准

回填 `=== 账本 ===` 到 `=== 结束 ===` 之间**原文**，外加首行 `commit_limit_gb=` 与 `exe=… bytes=… written=…`。

| 行 | 期望 |

| `threads that translate lists` | `threads=6` |
| `pipeline workers` | `workers=4` |
| `card buffer limits` | `vram_budget_mb=*`（动态值，任意） |
| `the card's room kept …` | **`most_mb=3072`**、`asked_mb=None`、`card_mb=*` |
