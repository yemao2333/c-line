## 命令

### S1 环境开关三方对比

```powershell
$trees = @{ A='G:\GTA\fork-eval\victory-fork'; B='G:\GTA\VIctory-Belobug-AMD-a-publier'; O='G:\GTA\cool_fox\cool_fox-main' }
$set = @{}
foreach ($k in $trees.Keys) {
  $set[$k] = @(Get-ChildItem $trees[$k] -Recurse -Include *.rs -ErrorAction SilentlyContinue |
    Select-String -Pattern 'VICTORY_[A-Z0-9_]+' -AllMatches |
    ForEach-Object { $_.Matches } | ForEach-Object { $_.Value } | Sort-Object -Unique)
  "$k count=$($set[$k].Count)"
}
"=== A_ONLY ==="; ($set['A'] | Where-Object { $set['O'] -notcontains $_ }) -join "`n"
"=== B_ONLY ==="; ($set['B'] | Where-Object { $set['O'] -notcontains $_ }) -join "`n"
"=== IN_BOTH_A_AND_B_NOT_O ==="; ($set['A'] | Where-Object { $set['B'] -contains $_ -and $set['O'] -notcontains $_ }) -join "`n"
```

### S2 模块缺口（.rs 相对路径差集，只列 ours 缺的）

```powershell
foreach ($k in 'A','B') {
  $p = $trees[$k]
  $fa = @(Get-ChildItem $p -Recurse -Filter *.rs | ForEach-Object { $_.FullName.Replace($p,'').TrimStart('\') } | Sort-Object)
  $fb = @(Get-ChildItem $trees['O'] -Recurse -Filter *.rs | ForEach-Object { $_.FullName.Replace($trees['O'],'').TrimStart('\') } | Sort-Object)
  "=== $k ONLY (我们缺的) ==="
  (Compare-Object $fa $fb | Where-Object SideIndicator -eq '<=' | ForEach-Object { $_.InputObject }) -join "`n"
}
```
