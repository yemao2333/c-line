## 目标

`r02-a11` 给出了世界的真实结构（原文）：

```
the card's clock per frame: nothing of ours queued 162.3 ms（卡约 58% 忙），
  其中 152.9 ms 发生在提交线程正在干活时（卡在我们身后空转）；
the submitting thread stood waiting for the card 226.7 ms
2.6 fps, 382.1 ms/frame（69.5 preparing：copies 29.1 ms / 127.7 MB；76.1 copying back 57.4 MB），3239 draws/frame
```

即**串行乒乓**：CPU 准备 ~150 ms（卡空转）→ 提交 → 等卡 227 ms。本任务打「拷贝与流水」这条线，四组各 200 s，全部 env、不重建、用 **release 产物**（不是 diag；diag 的 `VICTORY_GPU_TIMING` 会关掉 late-wait，帧时间不可比）。

| 序 | label | `-Extra` | 想验证 |
| --- | --- | --- | --- |
| 1 | `R6-control` | （无） | 控制组 |
| 2 | `R6-sendown0` | `VICTORY_SEND_OWN=0` | 每帧 127.7 MB「自己发上去」是不是白发的 |
| 3 | `R6-inplace0` | `VICTORY_COPIES_IN_PLACE=0` | 拷贝改在提交时做，是否反而更省 |
| 4 | `R6-latewait1` | `VICTORY_LATE_WAIT=1` | 少一层 late-wait 流水 |

> 前置：`commit_limit_gb ≥ 44`（现 49.84）；`target\release\victory.exe` SHA256 必须仍是 `58E60D62…A4EFF45`。

## 命令

```powershell
"SHA256=" + (Get-FileHash 'G:\GTA\cool_fox\cool_fox-main\target\release\victory.exe' -Algorithm SHA256).Hash
$c = (Get-Counter '\Memory\Commit Limit','\Memory\Committed Bytes' -SampleInterval 1 -MaxSamples 1).CounterSamples
$lim=($c|Where-Object Path -match 'commit limit').CookedValue/1GB; $used=($c|Where-Object Path -match 'committed bytes').CookedValue/1GB
"commit_limit_gb={0:N2} commit_free_gb={1:N2}" -f $lim,($lim-$used)
if ($lim -lt 44) { "SKIP_R6: commit_limit_gb < 44"; return }

Get-Process | Where-Object { $_.ProcessName -match '^victory' } | Stop-Process -Force -ErrorAction SilentlyContinue
Start-Sleep 3
cd G:\GTA\cool_fox-优化方案
$exe = 'G:\GTA\cool_fox\cool_fox-main\target\release\victory.exe'

powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\13-bench-ab.ps1 -Label R6-control   -Exe $exe -Seconds 200 -Profile fork
Get-Process | Where-Object { $_.ProcessName -match '^victory' } | Stop-Process -Force -ErrorAction SilentlyContinue; Start-Sleep 5

Get-Process | Where-Object { $_.ProcessName -match '^victory' } | Stop-Process -Force -ErrorAction SilentlyContinue; Start-Sleep 5
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\13-bench-ab.ps1 -Label R6-latewait1 -Exe $exe -Seconds 200 -Profile fork -Extra "VICTORY_LATE_WAIT=1"

$n=0; Get-Content .\data\bench-v2.csv | ForEach-Object { $n++; "{0,2}: {1}" -f $n,$_ }
```
