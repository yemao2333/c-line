## 目标

验证 **并行页映射**：`Start-GTA6.cmd` 与 `13-bench-ab.ps1` 都写了 `VICTORY_MAP_THREADS=1`，而代码默认是 **8**（`crates/victory-hle/src/modules/xmem.rs:1286`：「How many threads map a group of pages side by side（`VICTORY_MAP_THREADS`；8 unless set；1：the caller alone；`auto`：little 时 1，标题按页速流式时 WIDE）」）。

`r02-a11` 的世界结构显示：每帧 382.1 ms = **CPU 准备 ~150 ms（卡在身后空转 152.9 ms）** + 等卡 226.7 ms。页映射正落在这 150 ms 里，而且流式世界比菜单多出的就是这个。

四组各 200 s，**release 产物**（不用 diag；`VICTORY_GPU_TIMING` 会强制关掉 late-wait），env-only：

| 序 | label | `-Extra` | 想验证 |
| --- | --- | --- | --- |
| 1 | `R7-control` | （无，即 MAP_THREADS=1） | 复现今晚同口径 |
| 2 | `R7-map8` | `VICTORY_MAP_THREADS=8` | 代码默认值 |
| 3 | `R7-map4` | `VICTORY_MAP_THREADS=4` | 6 物理核下可能优于 8 |
| 4 | `R7-mapauto` | `VICTORY_MAP_THREADS=auto` | 交给实现自己判断 |

> 前置：`commit_limit_gb ≥ 44`（现 49.84）；`target\release\victory.exe` SHA256 = `58E60D62…A4EFF45`。
> 与 `r02-a12`（spec v1，拷BEI/流水三开关）**不冲突**：那是另一条线，四行照收。

## 命令

```powershell
"SHA256=" + (Get-FileHash '<ROOT>\cool_fox\cool_fox-main\target\release\victory.exe' -Algorithm SHA256).Hash
$c = (Get-Counter '\Memory\Commit Limit','\Memory\Committed Bytes' -SampleInterval 1 -MaxSamples 1).CounterSamples
$lim=($c|Where-Object Path -match 'commit limit').CookedValue/1GB; $used=($c|Where-Object Path -match 'committed bytes').CookedValue/1GB
"commit_limit_gb={0:N2} commit_free_gb={1:N2}" -f $lim,($lim-$used)
if ($lim -lt 44) { "SKIP_R7: commit_limit_gb < 44"; return }

Get-Process | Where-Object { $_.ProcessName -match '^victory' } | Stop-Process -Force -ErrorAction SilentlyContinue
Start-Sleep 3
cd <ROOT>\cool_fox-优化方案
$exe = '<ROOT>\cool_fox\cool_fox-main\target\release\victory.exe'

powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\13-bench-ab.ps1 -Label R7-control -Exe $exe -Seconds 200 -Profile fork
Get-Process | Where-Object { $_.ProcessName -match '^victory' } | Stop-Process -Force -ErrorAction SilentlyContinue; Start-Sleep 5
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\13-bench-ab.ps1 -Label R7-map8    -Exe $exe -Seconds 200 -Profile fork -Extra "VICTORY_MAP_THREADS=8"
Get-Process | Where-Object { $_.ProcessName -match '^victory' } | Stop-Process -Force -ErrorAction SilentlyContinue; Start-Sleep 5
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\13-bench-ab.ps1 -Label R7-map4    -Exe $exe -Seconds 200 -Profile fork -Extra "VICTORY_MAP_THREADS=4"
Get-Process | Where-Object { $_.ProcessName -match '^victory' } | Stop-Process -Force -ErrorAction SilentlyContinue; Start-Sleep 5
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\13-bench-ab.ps1 -Label R7-mapauto -Exe $exe -Seconds 200 -Profile fork -Extra "VICTORY_MAP_THREADS=auto"
Get-Process | Where-Object { $_.ProcessName -match '^victory' } | Stop-Process -Force -ErrorAction SilentlyContinue

$n=0; Get-Content .\data\bench-v2.csv | ForEach-Object { $n++; "{0,2}: {1}" -f $n,$_ }
```
