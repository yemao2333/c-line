## 目标

测 **「等显卡」这条链**上的三个开关：info 级日志（`data\ledger-a1-1126-223308.err.log`）显示稳定态每帧 ~287 ms 里有 **~197 ms 是在等显卡完成**（`title memory read` settle；回读线程 `waited 201.9 ms for the card with nothing to land`），CPU 列表翻译、fence、present 全是 0 ms。这三个开关都直接改这条链上的等待与回读量。

四组串行，各 200 s，同一产物（`victory.exe`，SHA256 `58E60D62…A4EFF45`），`-Profile fork`：

| 序 | label | `-Extra` | 想验证 |
| --- | --- | --- | --- |
| 1 | `R5-control` | （无） | 本轮控制组（干净会话首跑） |
| 2 | `R5-wideback0` | `VICTORY_WIDE_BACK=0` | 收窄回读宽度是否减少等待 |
| 3 | `R5-cardsteps0` | `VICTORY_CARD_STEPS=0` | 不做额外卡上步骤是否减少同步 |
| 4 | `R5-relaycopy0` | `VICTORY_RELAY_COPY=0` | 关掉 relay 拷贝回，改按需读 |

> 前置：`commit_limit_gb ≥ 44`（当前 49.84，直接放行）；用户已于 2026-11-26 23:50:31 重启，本任务是重启后的干净会话首轮。

## 命令

```powershell
# 0) 版本 + 额度守卫
"SHA256=" + (Get-FileHash '<ROOT>\cool_fox\cool_fox-main\target\release\victory.exe' -Algorithm SHA256).Hash
$c = (Get-Counter '\Memory\Commit Limit','\Memory\Committed Bytes' -SampleInterval 1 -MaxSamples 1).CounterSamples
$lim = ($c | Where-Object Path -match 'commit limit').CookedValue / 1GB
$used = ($c | Where-Object Path -match 'committed bytes').CookedValue / 1GB
"commit_limit_gb={0:N2} commit_used_gb={1:N2} commit_free_gb={2:N2}" -f $lim,$used,($lim-$used)
if ($lim -lt 44) { "SKIP_R5: commit_limit_gb < 44"; return }

Get-Process | Where-Object { $_.ProcessName -match '^victory' } | Stop-Process -Force -ErrorAction SilentlyContinue
Start-Sleep 3
cd <ROOT>\cool_fox-优化方案

powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\13-bench-ab.ps1 -Label R5-control -Exe "<ROOT>\cool_fox\cool_fox-main\target\release\victory.exe" -Seconds 200 -Profile fork
Get-Process | Where-Object { $_.ProcessName -match '^victory' } | Stop-Process -Force -ErrorAction SilentlyContinue
Start-Sleep 5

powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\13-bench-ab.ps1 -Label R5-wideback0 -Exe "<ROOT>\cool_fox\cool_fox-main\target\release\victory.exe" -Seconds 200 -Profile fork -Extra "VICTORY_WIDE_BACK=0"
Get-Process | Where-Object { $_.ProcessName -match '^victory' } | Stop-Process -Force -ErrorAction SilentlyContinue
Start-Sleep 5

powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\13-bench-ab.ps1 -Label R5-cardsteps0 -Exe "<ROOT>\cool_fox\cool_fox-main\target\release\victory.exe" -Seconds 200 -Profile fork -Extra "VICTORY_CARD_STEPS=0"
Get-Process | Where-Object { $_.ProcessName -match '^victory' } | Stop-Process -Force -ErrorAction SilentlyContinue
Start-Sleep 5

powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\13-bench-ab.ps1 -Label R5-relaycopy0 -Exe "<ROOT>\cool_fox\cool_fox-main\target\release\victory.exe" -Seconds 200 -Profile fork -Extra "VICTORY_RELAY_COPY=0"
```
