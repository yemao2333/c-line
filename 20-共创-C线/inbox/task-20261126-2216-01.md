## 目标

用**当前源码**（回滚版：窗口网格 4 MiB、首帧预留固定 3,072 MB、上卡内存固定 4,096 MB、分级阈值 1 MiB、快照池 1,024 / 保留 256 MB 均已还原）重建 `target\release\victory.exe`，产出 EXIT、字节数、写入时间、SHA256，供 `r02-a2`/`r02-a3` 绑定版本。

> 取代 `inbox\_superseded\task-20261126-2157-01.md`。round-01 跑的是 20:59 构建的第一版产物（未回滚），本任务之前的所有 B 组数字不作为依据。

## 命令

```powershell
$env:CARGO_HOME = "<RUST>\cargo"; $env:RUSTUP_HOME = "<RUST>\rustup"
$env:PATH = "<RUST>\cargo\bin;<TOOLCHAIN>\w64devkit\w64devkit\bin;C:\Windows\System32;" + $env:PATH

cd <ROOT>\cool_fox\cool_fox-main
$log = "<ROOT>\cool_fox-优化方案\data\build-r02-a1.log"
$t0 = Get-Date
cargo build --release --locked -p victory *> $log
"EXIT=$LASTEXITCODE elapsed=$([int]((Get-Date)-$t0).TotalSeconds)s"
$f = Get-Item target\release\victory.exe
"exe_bytes=$($f.Length) written=$($f.LastWriteTime.ToString('yyyy-MM-dd HH:mm:ss'))"
"SHA256=" + (Get-FileHash target\release\victory.exe -Algorithm SHA256).Hash
"errors=" + @(Select-String -Path $log -Pattern '^error' | Select-Object -First 5).Count
```

## 验收标准

| 项 | 通过线 | 判定方式 |
| --- | --- | --- |
| `EXIT` | 0 | 输出首行原样 |
| `errors` | 0 | 输出末行原样 |
| `exe_bytes` | 45,000,000 – 55,000,000 | 与 round-01 的 49,684,428 同量级 |
| `written` | 晚于 `2026-11-26 22:00` | 必须晚于源码最后一次修改 |
| `SHA256` | 64 位十六进制，非空 | `r02-a2`/`r02-a3` 回填里必须复述同一值 |

## 禁止事项

1. **不得改写任何数字**：`EXIT`、`elapsed`、字节数、时间戳、SHA256 一律原样粘贴，不改精度、不换算单位（`49,684,428 bytes` 不得写成 `47.4 MB` 充当字节数）。
2. **不得改变论证方向**：构建失败就是失败，不得写"不影响后续"。
3. **不得自行补充未经核实的结论**：不得推测 `+2.1 GB` 的来源、不得推测失败原因。
4. 不得修改任何源码、`Cargo.toml`、`.cargo\config.toml`、`rust-toolchain.toml`、`crates\victory-shader\**`、`crates\victory-core\src\policy.rs`。
5. 不得删除或覆盖 `target\release\victory-baseline.exe`（A 组对照物）。
6. 不得用 `-j` 并行、不得改 `[profile.release]`、不得加 `panic=abort`。
