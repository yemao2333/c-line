## 目标

做方案 §05 §2 **一直没做的那一步**：把管线册记下来并预热。依据是上游作者自己的性能日志 `docs/findings.md` §What is next 第 3 条：

> Stalls: 270-660 s of a session were full of frames over 200 ms, almost all while new pipelines were made. `victory warm`, and a quarter of the workers for the slow ones.

也就是：**世界里 >200 ms 的卡顿，绝大多数发生在「现场编译新 pipeline」时**。`victory warm --used` 可以把它们提前编好。本任务顺带量一下：预热前后，`Ms > 200` 的样本数降不降。

三步，串行：

| 步 | 做什么 | 时长 |
| --- | --- | --- |
| S1 | `VICTORY_PIPELINE_BOOK=1` 跑一局（记下这次用到的 pipeline），落 `pipeline book` | 200 s |
| S2 | `victory.exe warm --used --jobs 4`（按册预热，可中断） | 至多 ~20 分钟 |
| S3 | 预热后再跑一局（不带 BOOK），对比卡顿数与中位 | 200 s |

> 前置：`commit_limit_gb ≥ 44`；`target\release\victory.exe`（SHA256 `58E60D62…A4EFF45`）；**不要**用 diag 产物，**不要**开 `VICTORY_CAPTURE_FRAMES`/`RECORD_FRAMES`。
> 说明：`VICTORY_PIPELINE_BOOK=1` 只写缓存目录（`G:\GTA\victory-data\coolfox-cache`），不动源码与产物。

## 命令

```powershell
"SHA256=" + (Get-FileHash 'G:\GTA\cool_fox\cool_fox-main\target\release\victory.exe' -Algorithm SHA256).Hash
$c = (Get-Counter '\Memory\Commit Limit','\Memory\Committed Bytes' -SampleInterval 1 -MaxSamples 1).CounterSamples
$lim=($c|Where-Object Path -match 'commit limit').CookedValue/1GB; $used=($c|Where-Object Path -match 'committed bytes').CookedValue/1GB
"commit_limit_gb={0:N2} commit_free_gb={1:N2}" -f $lim,($lim-$used)
if ($lim -lt 44) { "SKIP_R8: commit_limit_gb < 44"; return }

Get-Process | Where-Object { $_.ProcessName -match '^victory' } | Stop-Process -Force -ErrorAction SilentlyContinue
Start-Sleep 3
cd G:\GTA\cool_fox-优化方案
$exe = 'G:\GTA\cool_fox\cool_fox-main\target\release\victory.exe'

# 管线册现状（前置读数）
"book_before=" + @(Get-ChildItem 'G:\GTA\victory-data\coolfox-cache\pipelines' -Recurse -File -ErrorAction SilentlyContinue).Count

# S1：带 BOOK 跑一局（同时作为「预热前」的卡顿基线）
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\13-bench-ab.ps1 -Label R8-before-book -Exe $exe -Seconds 200 -Profile fork -Extra "VICTORY_PIPELINE_BOOK=1"
Get-Process | Where-Object { $_.ProcessName -match '^victory' } | Stop-Process -Force -ErrorAction SilentlyContinue
Start-Sleep 3
"book_after_run=" + @(Get-ChildItem 'G:\GTA\victory-data\coolfox-cache\pipelines' -Recurse -File -ErrorAction SilentlyContinue).Count

# S2：按册预热
$t0 = Get-Date
& $exe warm --used --jobs 4 *> 'G:\GTA\cool_fox-优化方案\data\r02-a14-warm.log'
"warm_EXIT=$LASTEXITCODE warm_elapsed=$([int]((Get-Date)-$t0).TotalSeconds)s"
Get-Content 'G:\GTA\cool_fox-优化方案\data\r02-a14-warm.log' -Tail 6
"book_after_warm=" + @(Get-ChildItem 'G:\GTA\victory-data\coolfox-cache\pipelines' -Recurse -File -ErrorAction SilentlyContinue).Count

# S3：预热后再跑一局
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\13-bench-ab.ps1 -Label R8-after-warm -Exe $exe -Seconds 200 -Profile fork
Get-Process | Where-Object { $_.ProcessName -match '^victory' } | Stop-Process -Force -ErrorAction SilentlyContinue

$n=0; Get-Content .\data\bench-v2.csv | ForEach-Object { $n++; "{0,2}: {1}" -f $n,$_ }
```

### 卡顿口径（必须回填）

从 `data\r02-a14-console.log` 的两段采样里数一下，每组各报三个数：

```powershell
$log='G:\GTA\cool_fox-优化方案\data\r02-a14-console.log'
$cur=$null; $stat=@{}
foreach ($l in Get-Content $log) {
  if ($l -match '^label=(R8-\S+)') { $cur=$Matches[1]; $stat[$cur]=[pscustomobject]@{n=0;gt200=0;gt400=0} }
  if ($cur -and $l -match 'ms=\s*([\d.]+)\s+draws=\s*(\d+)' ) {
    $ms=[double]$Matches[1]; if ([int]$Matches[2] -lt 200) { continue }
    $stat[$cur].n++; if ($ms -gt 200) { $stat[$cur].gt200++ }; if ($ms -gt 400) { $stat[$cur].gt400++ }
  }
}
$stat.GetEnumerator() | ForEach-Object { "{0}: world_n={1} gt200={2} gt400={3}" -f $_.Key,$_.Value.n,$_.Value.gt200,$_.Value.gt400 }
```
