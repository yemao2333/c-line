## 目标

用**当前源码**（已回滚窗口网格/首帧预留/上卡内存/分级阈值/快照池）重建 `target\release\victory.exe`，拿到 EXIT、字节数、时间戳、SHA256。

> 为什么必须重建：round-01 跑的是 20:59 那次构建（`round-01\B-执行端回填.md:12`「沿用既有产物，本轮未重编」），而源码在 21:23 之后又改过。源码改动清单见 `20-共创-C线\round-02\A-代码侧简报.md` §5。

## 命令

```powershell
$env:CARGO_HOME = "<RUST>\cargo"; $env:RUSTUP_HOME = "<RUST>\rustup"
$env:PATH = "<RUST>\cargo\bin;<TOOLCHAIN>\w64devkit\w64devkit\bin;C:\Windows\System32;" + $env:PATH
$env:RUSTFLAGS = "-C target-cpu=native"
cd <ROOT>\cool_fox\cool_fox-main
$log = "<ROOT>\cool_fox-优化方案\data\build-r02-a1.log"
$t0 = Get-Date
cargo build --release --locked -p victory *> $log
"EXIT=$LASTEXITCODE elapsed=$([int]((Get-Date)-$t0).TotalSeconds)s"
$f = Get-Item target\release\victory.exe
"exe_bytes=$($f.Length) written=$($f.LastWriteTime.ToString('yyyy-MM-dd HH:mm:ss'))"
"SHA256=" + (Get-FileHash target\release\victory.exe -Algorithm SHA256).Hash
"errors=" + @(Select-String -Path $log -Pattern '^error' | Select-Object -First 5).Count
```

## 失败时回填什么

`data\build-r02-a1.log` 里从第一个 `error[` 起 40 行：

```powershell
Select-String -Path "<ROOT>\cool_fox-优化方案\data\build-r02-a1.log" -Pattern "error\[" -Context 0,40 | Select-Object -First 1 | ForEach-Object { $_.Line; $_.Context.PostContext }
```
