## 目标

用 info 级抓**卡内账本 5 行**，确认跑的是回滚版（`most_mb=3072`、上卡上限 `most_mb=4096`），并把 `card_mb` 这个「DXGI 动态预算」诊断字段一起带回来，回答 round-01 留下的 5,834 / 7,256 口径问题。

脚本自带 OOM 重试：info 级在这台机上有 3–5 秒被 `0x8007000E` 打死的概率（round-01 三次挂两次），死一次不算失败。

## 命令

```powershell
# 前置：r02-a1 EXIT=0
powershell.exe -NoProfile -ExecutionPolicy Bypass -File "<ROOT>\cool_fox-优化方案\16-ledger-probe.ps1" -Attempts 3 -Seconds 150
```

脚本会打印：

```
commit_limit_gb=… commit_used_gb=… commit_free_gb=…
exe=… bytes=… written=…
--- attempt 1 : data\ledger-a1-*.err.log ---
attempt 1: captured n / 5 lines
=== 账本 ===
（五行原文，缺的写 MISSING: <pattern>）
```

## 验收

回填 `=== 账本 ===` 到 `=== 结束 ===` 之间的**原文**，外加首行 `commit_limit_gb=` 与 `exe=… bytes=… written=…`。

通过线：

| 行 | 期望 |
| --- | --- |
| `threads that translate lists` | `threads=6` |
| `pipeline workers` | `workers=4` |
| `card buffer limits` | `vram_budget_mb=*`（动态值，任意） |
| `the card's room kept …` | **`most_mb=3072`**、`asked_mb=None`、`card_mb=*` ← 证明是回滚版 |
| `the card's most title memory …` | **`most_mb=4096`**、`card_mb=*` |

只要 `most_mb=3072 / 4096` 出现，就证明 `r02-a2` 跑的也是回滚版（同一份 exe，回填里带 SHA256 即可互证）。

## 失败时回填什么

- 三次 attempt 都 `captured < 5` → 把三次的 `attempt n: process gone after N s` 行 + 每次 `ledger-a*-*.err.log` 的最后 20 行贴回。
- 若 `commit_free_gb < 2`，在回填「异常」段写明：这是页面文件没扩的表现（`12-页面文件.ps1` 由人执行 + 重启），本任务按「墙下采样」记录，不再重复尝试。
- 若出现 `0x8007000E` / `ERROR_NOT_ENOUGH_MEMORY` 字样，连同最后 20 行一起贴回。
