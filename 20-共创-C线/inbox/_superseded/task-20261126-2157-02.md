## 目标

回滚版 vs 基线的 A/B：两组各 200 s，同一套环境变量（`-Profile fork`），拿到 `world_median_ms / max_draws / max_priv_gb / min_commit_free_gb` 与逐样本表，用来判定「+14.4% 帧时间 / +2.1 GB 提交」是否随回滚消失。

> 前置：`r02-a1` 必须 EXIT=0（否则跑的还是旧 exe，本任务作废）。

## 命令

```powershell
# 0) 额度守卫：通道说明 §硬边界「Commit Free 低于 6 GB 不启动」
$c = (Get-Counter '\Memory\Commit Limit','\Memory\Committed Bytes' -SampleInterval 1 -MaxSamples 1).CounterSamples
$limit = ($c | Where-Object Path -match 'commit limit').CookedValue / 1GB
$used  = ($c | Where-Object Path -match 'committed bytes').CookedValue / 1GB
$free  = [math]::Round($limit - $used, 2)
"commit_limit_gb=$([math]::Round($limit,2)) commit_free_gb=$free"
"exe_written=$((Get-Item 'G:\GTA\cool_fox\cool_fox-main\target\release\victory.exe').LastWriteTime.ToString('yyyy-MM-dd HH:mm:ss'))"

if ($free -lt 6) {
  "SKIP_BENCH: commit_free ${free} GB < 6 GB — 先扩页面文件再跑（12-页面文件.ps1，由人执行）"
} else {
  # 1) 清残留（按映像名，不用 pid）
  Get-Process | Where-Object { $_.ProcessName -match '^victory' } | Stop-Process -Force -ErrorAction SilentlyContinue
  Start-Sleep 3

  cd G:\GTA\cool_fox-优化方案
  # 2) 基线
  powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\13-bench-ab.ps1 `
    -Label R2-A2-baseline -Exe "G:\GTA\cool_fox\cool_fox-main\target\release\victory-baseline.exe" -Seconds 200 -Profile fork
  Get-Process | Where-Object { $_.ProcessName -match '^victory' } | Stop-Process -Force -ErrorAction SilentlyContinue
  Start-Sleep 5

  # 3) 回滚版
  powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\13-bench-ab.ps1 `
    -Label R2-B-reverted -Exe "G:\GTA\cool_fox\cool_fox-main\target\release\victory.exe" -Seconds 200 -Profile fork
  Get-Process | Where-Object { $_.ProcessName -match '^victory' } | Stop-Process -Force -ErrorAction SilentlyContinue

  # 4) 汇总
  Get-Content .\data\bench.csv -Tail 3
}
```

## 验收

回填三样：

1. `data\bench.csv` 新增的 **两行原文**（`R2-A2-baseline`、`R2-B-reverted`）。
2. 两次运行的**逐样本表**（`T / Ms / Draws / PrivGB`，脚本会打到控制台）——代码侧要按 draws 对齐判读。
3. 守卫行 `commit_limit_gb=… commit_free_gb=…` 原文。

判读阈值（代码侧会用同样的口径复核）：

| 指标 | 通过线 |
| --- | --- |
| `world_samples` | ≥ 8（少于 8 条这次运行作废） |
| `max_draws` | > 1000（否则没进世界） |
| `world_median_ms` | 新 ≤ 基线 |
| `max_priv_gb` | 新 ≤ 18.5（round-01 是 20.53） |
| 按 draws 对齐 | 不再出现 +49% / +88% 量级 |

## 失败时回填什么

- `SKIP_BENCH` 被打印 → 原文回填，不必跑。
- 中途崩溃/超时/空日志 → 该次运行 `data\run-<label>-*.log` 与 `*.err.log` 的**最后 20 行**，加上 `Get-Process victory*` 的残留检查结果。
- 出现两份以上 victory 进程 → 先 `Stop-Process -Force` 再重跑，并在异常段写明。
