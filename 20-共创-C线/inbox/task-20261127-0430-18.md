## 目标

评估「把我们的树切到 / 合并到 `fxceless/victory-fork`」的成本与收益。**只做取源、差异清点、隔离构建三件事；不跑游戏、不碰我们现有的树和缓存。**

背景（代码侧已核）：
- 我们的树 `<ROOT>\cool_fox\cool_fox-main`（CGBJ/codec-d 的 cool_fox，基于 VIctory + XCL）**不是 git 仓库**，没有历史可比；
- 目标 fork 的 README 自述：first boat mission **8.2–9.5 fps**（RTX 4070 / i7-14700KF），并带一整套我们树里**没有**的开关（`VICTORY_HEAP_WORKER`、`PARALLEL_REFRESH`、`SETTLE_ROOM`、`LOOKUP_CACHE`、`STEP_INDEX`、`FILLS_PLAIN`、`COPY_PLAIN`、`QUEUE2`、`ABSENT_ONCE`、`BVH_NO_HIT` 等）；
- 我们机器实测 ~4 fps（4,400 draws，`222.3 ms/帧`）。

## 命令

### S1 取源（只 clone，不 push、不改）

```powershell
$root = '<ROOT>\fork-eval'
New-Item -ItemType Directory -Force -Path $root | Out-Null
$dst = Join-Path $root 'victory-fork'
if (-not (Test-Path $dst)) {
  & git clone --depth 1 https://github.com/fxceless/victory-fork.git $dst 2>&1 | Out-String
}
"clone_EXIT=$LASTEXITCODE"
if (Test-Path $dst) {
  & git -C $dst log -1 --format='commit=%H%ndate=%ci%nsubject=%s' 2>&1
  & git -C $dst remote -v 2>&1
  "files=" + @(Get-ChildItem $dst -Recurse -File -ErrorAction SilentlyContinue).Count
  "size_mb=" + [math]::Round((Get-ChildItem $dst -Recurse -File -ErrorAction SilentlyContinue | Measure-Object Length -Sum).Sum / 1MB, 1)
}
```

### S2 差异清单（不构建，先出这张表）

```powershell
$theirs = '<ROOT>\fork-eval\victory-fork'
$ours   = '<ROOT>\cool_fox\cool_fox-main'

# (a) 环境开关全集差：他们的多出哪些
$a = @(Get-ChildItem $theirs -Recurse -Filter *.rs -ErrorAction SilentlyContinue |
       Select-String -Pattern 'VICTORY_[A-Z0-9_]+' -AllMatches |
       ForEach-Object { $_.Matches } | ForEach-Object { $_.Value } | Sort-Object -Unique)
$b = @(Get-ChildItem $ours -Recurse -Filter *.rs -ErrorAction SilentlyContinue |
       Select-String -Pattern 'VICTORY_[A-Z0-9_]+' -AllMatches |
       ForEach-Object { $_.Matches } | ForEach-Object { $_.Value } | Sort-Object -Unique)
"theirs_switches=$($a.Count) ours_switches=$($b.Count)"
"=== ONLY_IN_THEIRS ==="
(Compare-Object $a $b | Where-Object SideIndicator -eq '<=' | ForEach-Object { $_.InputObject }) -join "`n"
"=== ONLY_IN_OURS ==="
(Compare-Object $a $b | Where-Object SideIndicator -eq '=>' | ForEach-Object { $_.InputObject }) -join "`n"

# (b) 模块/源码文件差
$fa = @(Get-ChildItem $theirs -Recurse -Filter *.rs -ErrorAction SilentlyContinue | ForEach-Object { $_.FullName.Replace($theirs,'').TrimStart('\') } | Sort-Object)
$fb = @(Get-ChildItem $ours   -Recurse -Filter *.rs -ErrorAction SilentlyContinue | ForEach-Object { $_.FullName.Replace($ours,'').TrimStart('\') } | Sort-Object)
"rs_theirs=$($fa.Count) rs_ours=$($fb.Count)"
"=== RS_ONLY_IN_THEIRS ==="; (Compare-Object $fa $fb | Where-Object SideIndicator -eq '<=' | ForEach-Object { $_.InputObject }) -join "`n"
"=== RS_ONLY_IN_OURS ===";   (Compare-Object $fa $fb | Where-Object SideIndicator -eq '=>' | ForEach-Object { $_.InputObject }) -join "`n"

# (c) 构建配置
"=== theirs rust-toolchain.toml ==="; Get-Content (Join-Path $theirs 'rust-toolchain.toml') -ErrorAction SilentlyContinue
"=== theirs [profile.*] ==="; Select-String -Path (Join-Path $theirs 'Cargo.toml') -Pattern '^\[profile\.' -ErrorAction SilentlyContinue | ForEach-Object { $_.Line }
"=== ours [profile.*] ===";    Select-String -Path (Join-Path $ours   'Cargo.toml') -Pattern '^\[profile\.' -ErrorAction SilentlyContinue | ForEach-Object { $_.Line }
"=== theirs workspace members ==="; Select-String -Path (Join-Path $theirs 'Cargo.toml') -Pattern 'members|exclude' -ErrorAction SilentlyContinue | ForEach-Object { $_.Line.Trim() }
"=== ours workspace members ===";   Select-String -Path (Join-Path $ours   'Cargo.toml') -Pattern 'members|exclude' -ErrorAction SilentlyContinue | ForEach-Object { $_.Line.Trim() }
```

### S3 隔离构建（不覆盖我们的产物）

```powershell
$theirs = '<ROOT>\fork-eval\victory-fork'
$env:CARGO_TARGET_DIR = '<ROOT>\fork-eval\target'          # 隔离 target，绝不写我们的 target
$env:CARGO_HOME = '<RUST>\cargo'; $env:RUSTUP_HOME = '<RUST>\rustup'
$env:PATH = '<RUST>\cargo\bin;<TOOLCHAIN>\w64devkit\w64devkit\bin;C:\Windows\System32;' + $env:PATH
$env:RUSTFLAGS = ''
$log = '<ROOT>\fork-eval\build-e1.log'
$t0 = Get-Date
Push-Location $theirs
cargo build --release --locked -p victory *> $log
"build_EXIT=$LASTEXITCODE elapsed=$([int]((Get-Date)-$t0).TotalSeconds)s"
Pop-Location
"errors=" + @(Select-String -Path $log -Pattern '^error' | Select-Object -First 5).Count
Get-Content $log -Tail 12
$exe = '<ROOT>\fork-eval\target\release\victory.exe'
if (Test-Path $exe) { $i=Get-Item $exe; "exe_bytes=$($i.Length) written=$($i.LastWriteTime)"; "exe_sha256=" + (Get-FileHash $exe -Algorithm SHA256).Hash } else { "exe=NOT_FOUND" }
"our_release_sha256=" + (Get-FileHash '<ROOT>\cool_fox\cool_fox-main\target\release\victory.exe' -Algorithm SHA256).Hash
```

> `--locked` 若失败（对方 `Cargo.lock` 与 `Cargo.toml` 不一致），**不要改装**：照实回填错误，改用 `--offline` 试一次，仍失败就停。

## 禁止事项

1. **不得改写任何数字**：commit、计数、EXIT、耗时、SHA256 一律原样。
2. **不得改变论证方向**：只列差异，不写"能不能合并、值不值"——那是代码侧的结论。
3. **不得自行补充未经核实的结论**：不解释对方开关的作用。
4. **不得改动我们的树**：`<ROOT>\cool_fox\cool_fox-main` 下任何文件（含 `target\`、`Cargo.toml`、`.cargo\config.toml`）都不许写。
5. **不得动我们的缓存**：`<ROOT>\victory-data\coolfox-cache` 不许写、不许删。
6. **不得运行游戏**（`victory.exe run`/`--execute` 一律不许）；本项目只做取源＋清点＋构建。
7. 网络只用于 `git clone`；不得 push、不得提交、不得改对方的工作区（不许 `cargo add`/`cargo update`/编辑源码解决编译错误）。
8. 不得删除 `<ROOT>\fork-eval` 下任何东西；失败重试也保留旧日志。

## 失败时回填什么

- clone 失败（404/网络）→ 贴 `git clone` 原始输出；改试 `https://github.com/fxceless/victory-fork` 的 zip 下载**只在 clone 全败时**，并注明来源。
- 构建失败 → `build-e1.log` 里第一个 `error[` 起 40 行 + `build_EXIT`。**不要试图修源码。**
- 磁盘不足 → 报 `Get-PSDrive C,G` 原文并停。
