## 目标

**同一假设的修正执行**（`r02-a14` 未真正执行：`warm` 报 `0 pipelines known ... 0 to make`，等于没预热任何东西，所以那两行的 267.8 / 256.1 不能当结果）。

代码侧从源码定位到两个可能原因，本任务把它们一起排掉：

1. **`--used` 会按「先用的那些」过滤**（`apps\victory\src\warm.rs:60`：`(!used || early.contains(key))`），而 `early-pipelines.txt` 只有在**跑过之后**才存在（本次 01:53:29 才生成，晚于 `warm` 的 01:51:33）⇒ 用 `--used` 时集合为空，`0 to make` 是必然。**本任务改用不带 `--used` 的 `victory warm`。**
2. **管线册可能只在干净退出时完整落盘**：S1 那个 200 s 会话是被 `Stop-Process -Force` 杀掉的。**本任务改成先 `CloseMainWindow()` 优雅关闭，等最多 60 s 再兜底强杀**，并记录 `clean_exit=True/False`。

另外加一条**决定性诊断**：若仍报 `0 pipelines known`，把 `known-pipelines.bin` 前 32 字节的十六进制回填，代码侧据此判断是不是册格式/版本问题。

## 命令

```powershell
"SHA256=" + (Get-FileHash '<ROOT>\cool_fox\cool_fox-main\target\release\victory.exe' -Algorithm SHA256).Hash
$c = (Get-Counter '\Memory\Commit Limit','\Memory\Committed Bytes' -SampleInterval 1 -MaxSamples 1).CounterSamples
$lim=($c|Where-Object Path -match 'commit limit').CookedValue/1GB; $used=($c|Where-Object Path -match 'committed bytes').CookedValue/1GB
"commit_limit_gb={0:N2} commit_free_gb={1:N2}" -f $lim,($lim-$used)
if ($lim -lt 44) { "SKIP_R9: commit_limit_gb < 44"; return }

$cache = '<ROOT>\victory-data\coolfox-cache\pipelines'
"before: known_pipelines_bytes=" + (Get-Item "$cache\known-pipelines.bin" -ErrorAction SilentlyContinue).Length
$env:VICTORY_AMBIENT_AIR='1.5'; $env:VICTORY_CACHE_DIR='<ROOT>\victory-data\coolfox-cache'; $env:VICTORY_DATA_DIR='<ROOT>\victory-data\coolfox-data'
$env:VICTORY_TEXTURE_NO_WAIT='1'; $env:VICTORY_RELAY='2'; $env:VICTORY_WIDE_BACK='1'; $env:VICTORY_CARD_REHASH_RUNS='1'
$env:VICTORY_JOIN_COPIES='1'; $env:VICTORY_INDIRECT_WINDOW='1'; $env:VICTORY_RELAY_COPY='1'; $env:VICTORY_CARD_STEPS='2'
$env:VICTORY_INDIRECT_BATCH='2'; $env:VICTORY_MAP_THREADS='1'; $env:VICTORY_CARD_AWAKE='1'; $env:VICTORY_SHOW_AFTER='1'
$env:VICTORY_AMBIENT='0.8'; $env:VICTORY_THIN='1'; $env:VICTORY_JOIN_PARTS='6'; $env:VICTORY_UPLOAD_AHEAD='1'
$env:VICTORY_LEVELS_ON_DEMAND='1'; $env:VICTORY_CARD_BUFFERS_MIN_KB='64'
$env:VICTORY_LOG = 'warn'
$env:VICTORY_PIPELINE_BOOK = '1'

Get-Process | Where-Object { $_.ProcessName -match '^victory' } | Stop-Process -Force -ErrorAction SilentlyContinue
Start-Sleep 3
$exe = '<ROOT>\cool_fox\cool_fox-main\target\release\victory.exe'
$err = '<ROOT>\cool_fox-优化方案\data\r02-a15-book.err.log'
$out = '<ROOT>\cool_fox-优化方案\data\r02-a15-book.log'
$p = Start-Process -FilePath $exe -ArgumentList @('run','<ROOT>\<DUMP>\game_scarlett_master.exe','--console','series-s','--execute') `
  -WorkingDirectory '<ROOT>\cool_fox\cool_fox-main' -RedirectStandardOutput $out -RedirectStandardError $err -PassThru -WindowStyle Normal
"pid=$($p.Id)"
Start-Sleep -Seconds 200
$v = Get-Process -Id $p.Id -ErrorAction SilentlyContinue
"title_before_close=" + $(if($v){$v.MainWindowTitle}else{'gone'})

# 优雅关闭：先 CloseMainWindow，等最多 60 s
$clean = $false
if ($v) { $null = $v.CloseMainWindow() }
for ($i=0; $i -lt 60; $i++) {
  Start-Sleep -Seconds 1
  if (-not (Get-Process -Id $p.Id -ErrorAction SilentlyContinue)) { $clean = $true; break }
}
"clean_exit=$clean waited_s=$i"
Get-Process | Where-Object { $_.ProcessName -match '^victory' } | Stop-Process -Force -ErrorAction SilentlyContinue
Start-Sleep 2
"after_close: known_pipelines_bytes=" + (Get-Item "$cache\known-pipelines.bin" -ErrorAction SilentlyContinue).Length
"after_close: leftover=" + @(Get-Process | Where-Object { $_.ProcessName -match '^victory' }).Count

# 不带 --used 预热（关键修正）
$t0 = Get-Date
& $exe warm --jobs 4 *> '<ROOT>\cool_fox-优化方案\data\r02-a15-warm.log'
"warm_EXIT=$LASTEXITCODE warm_elapsed=$([int]((Get-Date)-$t0).TotalSeconds)s"
Get-Content '<ROOT>\cool_fox-优化方案\data\r02-a15-warm.log' -Tail 8
"warm_line=" + ((Select-String -Path '<ROOT>\cool_fox-优化方案\data\r02-a15-warm.log' -Pattern 'pipelines known' | Select-Object -First 1).Line)

# 若仍 0 known：回填册头 32 字节
$hdr = Get-Content "$cache\known-pipelines.bin" -Encoding Byte -TotalCount 32 -ErrorAction SilentlyContinue
"known_pipelines_head32=" + (($hdr | ForEach-Object { '{0:x2}' -f $_ }) -join '')

# 预热后再跑一局，量卡顿
Remove-Item Env:\VICTORY_PIPELINE_BOOK -ErrorAction SilentlyContinue
cd <ROOT>\cool_fox-优化方案
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\13-bench-ab.ps1 -Label R9-after-warm2 -Exe $exe -Seconds 200 -Profile fork
Get-Process | Where-Object { $_.ProcessName -match '^victory' } | Stop-Process -Force -ErrorAction SilentlyContinue
$n=0; Get-Content .\data\bench-v2.csv | ForEach-Object { $n++; if ($n -ge 20) { "{0,2}: {1}" -f $n,$_ } }
```
