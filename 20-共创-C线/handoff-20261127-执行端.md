## 7 下次开工的硬约束（本机踩过的坑）

1. 工具进程 PATH 默认无 `System32`：裸 `powershell.exe` / `taskkill` 会找不到，一律 `$env:SystemRoot\System32\...` 全路径。
2. `.ps1` 必须 UTF-8 **带 BOM**，写完先过 `Parser::ParseFile`；runner 全 ASCII 优先。
3. 内层 PS 5.1 输出是 GBK：要么用 GBK 解码转 UTF-8（`GetEncoding(936)`），要么在 pwsh 里直接跑；否则中文变 `?`/乱码。
4. 长组不塞进单次工具调用：detach 的 `Start-Process` + 轮询；`WaitForExit(毫秒)` 别当秒用。
5. 按映像名 `^victory` 收尾；`-Name victory` 匹配不到 `victory-baseline`。
6. 两局不并发；每组之间清残留并复核 `leftover_procs`。
7. 不开 `VICTORY_CAPTURE_FRAMES` / `VICTORY_RECORD_FRAMES`；不用 diag 产物做帧时间比较。
